# Mackey-Glass Time-Series Prediction with LSTM and ESN

This repository implements two recurrent approaches for **one-step-ahead time-series prediction**:

- **Long Short-Term Memory (LSTM)**
- **Echo State Network (ESN)**

The project has currently been tested on the **Mackey-Glass chaotic time series with delay parameter τ = 17 (MG17)**. Performance on other time series has not yet been validated and will be investigated in future work.

## Repository Workflows

The repository is organized into three main workflows, which can be executed independently through the corresponding entry-point scripts:

- **Main experiment — `main.py`**  
  Runs the complete LSTM and ESN prediction pipeline.

- **Hyperparameter tuning — `fine_tuning.py`**  
  Performs random-search hyperparameter optimization for the LSTM and ESN models.

- **Graphical user interface — `app.py`**  
  Launches the Gradio-based interface for loading and preprocessing data, training or loading pretrained models, performing hyperparameter tuning, visualizing results, and downloading model configurations and weights.

## Main Experiment — `main.py`

The `main.py` script runs the complete LSTM and ESN prediction pipeline. All the files required by this workflow are contained in the `main/` directory, which is organized as follows:

- **`input/`**  
  Contains the input files required to run the experiment:
  - `input.csv`: contains the input time series.
  - `config.json`: contains the data-processing settings and the configuration parameters for the LSTM and ESN models.

- **`output/`**  
  Contains the results generated by the experiment, including model performance metrics and plots.

- **`weights/`**  
  Contains the saved model weights for the LSTM and ESN networks.

- **`source_code/`**  
  Contains the source code used by the main workflow:
  - `utils.py`: contains common utility functions used for data processing, evaluation, plotting, and other shared operations.
  - `lstm_model.py`: contains the code specific to the LSTM model.
  - `esn_model.py`: contains the code specific to the ESN model.

## Hyperparameter Tuning — `fine_tuning.py`

The `fine_tuning.py` script performs hyperparameter tuning for both the LSTM and ESN models using random search. All the files associated with this workflow are contained in the `fine_tuning/` directory, which is organized as follows:

- **`input/`**  
  Contains the files used to define the hyperparameter search:
  - **`configs/`**: contains the CSV files listing the hyperparameter configurations tested for the LSTM and ESN models.
  - **`search_spaces/`**: contains the JSON files defining the hyperparameter values and ranges used to randomly generate the configurations for each model.

- **`output/`**  
  Contains the results generated by the random search, including the results obtained for the tested configurations and the best result found for each model.

- **`source_code/`**  
  Contains the source code used for hyperparameter tuning:
  - `tuning.py`: contains the functions used to generate the random configurations, evaluate them, and identify the configuration with the best validation performance.

## Graphical User Interface — `app.py`

The `app.py` script provides the graphical user interface of the project, developed using **Gradio**. The interface allows the user to interact with the main functionalities of the project without directly modifying the source code.

The files associated with the graphical interface are contained in the `gui/` directory, which is organized as follows:

- **`input/`**  
  Contains a copy of the time-series dataset uploaded by the user through the interface.

- **`config/`**  
  Contains the JSON configuration files associated with the LSTM and ESN models, containing hyperparameters. These configurations can be generated from manually entered hyperparameters or loaded from existing JSON files. Unlike the `config.json` file used by `main.py`, which contains the configurations for both models in a single file, the GUI stores the LSTM and ESN configurations in two separate JSON files:
  - `lstm_config.json`: contains the LSTM configuration.
  - `esn_config.json`: contains the ESN configuration.

- **`weights/`**  
  Contains the `.pt` files storing the LSTM and ESN model weights. The weights can either be generated by training a new model or provided by the user when loading a pretrained model.

- **`fine_tuning/`**  
  Contains the files generated by the hyperparameter tuning procedures launched through the graphical interface, including the tested configurations, tuning results, and best configurations found for the LSTM and ESN models.

- **`utils.py`**  
  Contains the functions used to connect the graphical interface with the data-processing, model-training, prediction, and hyperparameter-tuning functionalities implemented in the rest of the project. 

## Installation and Usage

### Installation

The project was developed and tested using **Python 3.12**.

It is recommended to create and activate a Python virtual environment before installing the required dependencies.

Install the project dependencies with:

```bash
python -m pip install -r requirements.txt
```

### Running the Main Experiment

To run the complete LSTM and ESN prediction pipeline:

```bash
python main.py
```

Before running the script, make sure that the input time series and configuration file are available in `main/input/`.

### Running Hyperparameter Tuning

To perform random-search hyperparameter tuning for the LSTM and ESN models:

```bash
python fine_tuning.py
```

The hyperparameter search spaces and generated configurations are stored in the corresponding directories inside `fine_tuning/`.

### Running the Graphical User Interface

To launch the Gradio graphical interface:

```bash
python app.py
```

The interface can then be accessed through the local address displayed in the terminal.
